访客留言

这里是你一个人的收件箱。访客在主页提交的留言会直接进入这个列表，页面本身不会公开任何内容。

还差一步：填写 Supabase 凭证

这个后台需要连上你自己的 Supabase 数据库。请先按下面的顺序把凭证补齐：

1. 打开 Supabase 控制台 → Project Settings → API Keys 2. 复制 Project URL 和 anon public key 3. 打开本目录下的 admin.html，找到文件底部「后台配置」那两行 4. 把两个空字符串替换成你的凭证，保存后刷新本页
注意：主页 wyw个人主页-V3.1.html 里也有同样的两行配置，两边都要填，留言才能一路打通。
完整图文步骤见 docs/supabase-接入指南.md。

作者登录

用你在 Supabase 里创建的管理员邮箱和密码登录，登录后才能读取留言。

还没有账号？在 Supabase 控制台 Authentication → Users → Add user 里手动建一个，并关闭公开注册。步骤见接入指南。
